# История изменений

## 1.9.0

- необязательная блокировка физического движения, кликов и колеса мыши во время воспроизведения записи или сценария;
- собственные события MacroPilot помечаются и продолжают проходить через Windows `SendInput` при включённой блокировке;
- клавиатура не блокируется, поэтому глобальная аварийная остановка `F12` остаётся доступной;
- низкоуровневый перехватчик работает в отдельном потоке и обязательно снимается при остановке, завершении или ошибке;
- перед выполнением сбрасывается возможное физическое удержание ЛКМ, ПКМ и СКМ, чтобы кнопка не осталась зажатой в игре;
- настройка выключена по умолчанию и доступна только в Windows.

## 1.8.0

- команды `WAIT_IMAGE` и `CLICK_IMAGE` для ожидания эталона на экране и клика по его центру;
- настраиваемые тайм-аут и порог сходства, бесконечное ожидание до F12 и поддержка нескольких мониторов;
- исправлены Ctrl+C, Ctrl+V, Ctrl+X, Ctrl+A, Ctrl+Z и Ctrl+Y в редакторе при русской раскладке;
- для игр добавлен минимум 40 мс удержания и 20 мс между кликами независимо от ускорения макроса;
- Windows-сборка переведена с самораспаковывающегося `--onefile` на переносимую папку `--onedir`;
- автообновление больше не запускает PowerShell с `ExecutionPolicy Bypass` и применяет ZIP внутренним проверяемым механизмом.

## 1.7.0

- физическое относительное движение мыши через Windows Raw Input во время удержания ЛКМ, ПКМ или СКМ;
- игнорирование служебных возвратов курсора в центр, которые выполняют игры с захватом мыши;
- воспроизведение записанных игровых движений относительными событиями Windows `SendInput`;
- команда сценария `MOVE_BY` теперь отправляет настоящее относительное движение, не вычисляя абсолютную позицию курсора;
- запись обычных движений мыши включена по умолчанию;
- совместимость загрузки со всеми ранее сохранёнными макросами.

## 1.6.1

- исправлен перезапуск после автоматического обновления: новый EXE больше не наследует удалённую временную папку `_MEI` старой версии;
- версия PyInstaller для релизных сборок закреплена, чтобы одинаковый исходный код создавал предсказуемые Windows-сборки.

## 1.6.0

- компактное сохранение JSON: длинные записи занимают примерно вдвое меньше места;
- безопасный лимит открытия макроса увеличен с 20 до 128 МБ;
- звуковое и текстовое предупреждение после 800 000 событий;
- автоматическая остановка около 1 000 000 событий с сохранением отпусканий зажатых клавиш и кнопок;
- четыре режима точности записи движения мыши: от экономного до максимального;
- глобальная клавиша `F9` для начала записи;
- предупреждение перед заменой уже существующей записи;
- дозапись нового фрагмента с продолжением временной шкалы текущего макроса;
- полная совместимость с макросами, сохранёнными предыдущими версиями.

## 1.5.1

- запасная проверка обновлений через публичную страницу GitHub Releases при HTTP 403/429;
- понятное сообщение о временном лимите GitHub, если недоступны оба способа проверки;
- официальная ссылка поддержки проекта;
- исходный код опубликован под лицензией MIT.

## 1.5.0

- новый тёмный интерфейс;
- вкладка автора и поддержки проекта;
- проверка обновлений через GitHub Releases;
- безопасная загрузка ZIP с проверкой SHA-256 и путей;
- автоматическая установка после закрытия и перезапуск приложения;
- GitHub Actions для тестов, Windows-сборки и публикации релизов.

## 1.4.0

- нативная игровая мышь Windows `SendInput`;
- исправление DPI-координат и поддержка виртуального рабочего стола;
- корректное перетаскивание объектов в Roblox.

## 1.3.2

- мгновенное начало записи;
- ожидание готовности перехватчиков;
- захват уже зажатых клавиш;
- удаление автоповторов `KEY_DOWN` без сокращения удержания.
