# MacroPilot 2.0.0

[![CI](https://github.com/Not-Config/MacroPilot/actions/workflows/ci.yml/badge.svg)](https://github.com/Not-Config/MacroPilot/actions/workflows/ci.yml)
[![Releases](https://img.shields.io/github/v/release/Not-Config/MacroPilot?display_name=tag)](https://github.com/Not-Config/MacroPilot/releases)
[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](LICENSE)

MacroPilot — локальный игровой кликер и редактор макросов на Python от **Config** для записи и воспроизведения действий мыши и клавиатуры. В него встроены безопасный сценарный язык и визуальный node-граф в стиле Blender для собственных последовательностей кликов и нажатий.

## Возможности

- запись нажатий и отпусканий клавиш;
- запись кликов, прокрутки, игровых перетаскиваний и всех движений мыши (включено по умолчанию);
- четыре режима точности траектории мыши — от 20 до 200 точек в секунду;
- глобальный запуск текущего макроса по `F8` и записи по `F9`;
- переназначение клавиш запуска, записи, завершения записи и аварийной остановки;
- продолжение существующего макроса без потери уже записанных событий;
- воспроизведение с регулируемой скоростью и числом повторов;
- бесконечное повторение до назначенной клавиши остановки (`F12` по умолчанию);
- необязательная блокировка физического движения, кликов и колеса мыши на время воспроизведения;
- физические Windows scan-коды и `SendInput` для корректных игровых клавиш независимо от раскладки;
- нативные события мыши Windows `SendInput` для игровых интерфейсов и перетаскиваний в Roblox;
- физические относительные движения Windows Raw Input при удержании кнопки мыши — без ложных прыжков от возврата курсора игрой в центр;
- корректные физические координаты при масштабе экрана Windows 125–200%;
- современный тёмный интерфейс на Qt/PySide6 с отдельным разделом проекта и автора;
- проверка, загрузка и установка обновлений из публичных GitHub Releases;
- компактное сохранение и загрузка макросов в совместимом формате JSON;
- удаление отдельных событий и преобразование записи в редактируемый сценарий;
- визуальная сборка сценариев на бесконечном холсте из связанных узлов действий, условий, циклов и значений;
- типизированные цветные порты, кривые связи, поиск узлов, масштабирование, панорамирование, копирование и вставка;
- сохранение графов в отдельные файлы `*.mpgraph` и двустороннее преобразование графа и кода;
- подсветка активного узла во время выполнения графа;
- команды кликов, перемещений, текста, горячих клавиш, пауз и циклов;
- ожидание появления PNG/JPG/BMP на экране и клик по найденному изображению;
- локальное чтение текста или числа из выбранной области экрана;
- переменные, текстовые и числовые условия `IF/ELSE` для работы с результатом OCR;
- мгновенное начало записи и обратный отсчёт перед воспроизведением;
- глобальная аварийная остановка по `F12` по умолчанию;
- завершение записи по `F10` или аварийной клавише по умолчанию;
- автоматическое отпускание зажатых приложением клавиш и кнопок мыши после остановки.

Записанные действия никуда не отправляются и хранятся локально после явного сохранения пользователем. При запуске MacroPilot обращается к публичным GitHub Releases, чтобы проверить наличие новой версии. Само обновление скачивается и устанавливается только после подтверждения пользователя.

Версия 2.0 переносит приложение на Qt/PySide6 и заменяет прежнее дерево блоков настоящим графом. Узлы можно свободно раскладывать на холсте и соединять портами; граф компилируется в тот же проверяемый язык MacroPilot, поэтому игровой движок и старые текстовые сценарии остаются совместимыми.

## Скачать готовую версию для Windows

1. Скачайте [`MacroPilot-windows.zip`](https://github.com/Not-Config/MacroPilot/releases/latest/download/MacroPilot-windows.zip) из последнего официального релиза.
2. Распакуйте всю папку `MacroPilot` в удобное место.
3. Запустите `MacroPilot.exe` из этой папки. Не переносите EXE отдельно от `_internal`; Python и установка зависимостей не требуются.

Готовая папка с EXE собирается автоматически на чистом Windows-сервере GitHub Actions из опубликованного исходного кода. Релиз также содержит `MacroPilot-source.zip` для разработчиков.

Пока EXE не подписан сертификатом издателя, SmartScreen может показать предупреждение о неизвестном издателе. Если Защитник Windows сообщает именно о вирусе или потенциально нежелательной программе, не восстанавливайте файл из карантина и не добавляйте исключение. Скачайте актуальный ZIP заново; спорное срабатывание можно [отправить Microsoft на проверку](https://www.microsoft.com/en-us/wdsi/filesubmission).

## Запуск из исходного кода

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/) и включите пункт **Add Python to PATH**.
2. Распакуйте исходный архив в обычную папку.
3. Дважды щёлкните `run_windows.bat`.

При первом запуске скрипт создаст виртуальное окружение и установит зависимости из `requirements.txt`.

Запуск вручную:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

## Как записать макрос

1. На вкладке **Запись** выберите точность траектории и нажмите **Начать / продолжить**. Запись также можно запустить глобальной клавишей `F9` по умолчанию, не переключаясь из игры.
2. Запись начнётся сразу после готовности перехватчиков, затем окно автоматически свернётся — выполните нужные действия. Автосворачивание можно выключить флажком.
3. Нажмите `F10` для завершения записи. `F12` также останавливает запись — это стандартные назначения.
4. Проверьте список событий, при необходимости удалите лишние строки.
5. Заранее откройте целевое окно и нажмите **Воспроизвести** или стандартную глобальную клавишу `F8`. После отсчёта MacroPilot свернётся; `F12` остановит выполнение.
6. Нажмите **Сохранить**, чтобы получить файл `*.macro.json`.

Для бесконечного цикла включите **∞ До F12** рядом с числом повторов. Поле количества повторов отключится, а макрос будет выполняться до глобального нажатия `F12`.

На вкладке **Настройки** можно назначить разные клавиши `F1`–`F20` для запуска текущего макроса, начала записи, завершения записи и аварийной остановки. Изменения применяются сразу и сохраняются между запусками. Во время записи все четыре служебные клавиши исключаются из записываемых событий.

Флажок **Блокировать физическую мышь** доступен в параметрах обеих вкладок и выключен по умолчанию. Если его включить, после начала воспроизведения Windows не передаст игре ваши физические движения, клики и прокрутку; события, созданные MacroPilot, продолжат проходить. Клавиатура не блокируется, поэтому для остановки используйте `F12`. Блокировка автоматически снимается при обычном завершении, ошибке и аварийной остановке. Функция доступна только в Windows и действует только во время воспроизведения — запись она не затрагивает.

Перед запуском с блокировкой отпустите физические кнопки мыши. MacroPilot дополнительно отправляет отпускания ЛКМ, ПКМ и СКМ перед первой командой, чтобы уже зажатая кнопка не осталась активной в игре. В бесконечном цикле заранее убедитесь, что глобальная клавиша `F12` работает.

Флажок **Записывать движения мыши** включён по умолчанию. Если его выключить, координаты каждого клика и вся траектория движения с зажатой кнопкой всё равно сохраняются и правильно воспроизводятся.

В Windows при удержании ЛКМ, ПКМ или СКМ MacroPilot переключается на физические относительные смещения Raw Input. Это подходит для игр, которые скрывают курсор или постоянно возвращают его в центр: такие служебные телепортации не попадут в макрос. При воспроизведении смещения отправляются относительными событиями `SendInput`, а после преобразования записи в сценарий сохраняются как команды `MOVE_BY`.

Если в таблице уже есть события, перед новой записью MacroPilot предложит три действия: **продолжить**, **перезаписать** или **отменить**. При продолжении старые события остаются на месте, а временные метки нового фрагмента автоматически начинаются после конца текущего макроса. Это позволяет дозаписать оборванную последовательность; состояние самой игры перед продолжением нужно вернуть в нужную точку самостоятельно.

Режим **Обычная · 40/с** сохраняет прежний баланс точности и размера. Экономный режим подходит для долгих плавных перемещений, а высокая и максимальная точность — для быстрых движений и небольших объектов. При перетаскивании с зажатой кнопкой MacroPilot автоматически записывает траекторию плотнее выбранного обычного режима.

Жёсткого ограничения по времени нет: приложение хранит до миллиона событий. В обычном режиме постоянное движение мыши помещается примерно в 6 часов 56 минут, а непрерывное перетаскивание — в 4 часа 26 минут; выбранная точность изменяет эти значения. После 800 000 событий MacroPilot один раз предупредит звуком и в строке состояния, а около предела автоматически завершит запись, сохранив отпускания зажатых клавиш и кнопок. Макросы загружаются из файлов размером до 128 МБ; новый компактный формат полностью совместим со старыми файлами версии 1.

## Онлайн-обновления

MacroPilot проверяет последний публичный релиз в репозитории [`Not-Config/MacroPilot`](https://github.com/Not-Config/MacroPilot). Проверку также можно запустить вручную кнопкой **Проверить обновления** в шапке или на вкладке **О проекте**.

Сначала приложение использует GitHub API. Если GitHub отвечает HTTP 403 или 429 из-за временного лимита, MacroPilot автоматически получает номер версии через публичную страницу Releases. Секретный токен для этого не требуется и в приложение не встраивается.

Если найдена более новая версия, приложение:

1. показывает номер версии и описание релиза;
2. запрашивает подтверждение;
3. скачивает подходящий ZIP-архив;
4. проверяет контрольную сумму и безопасную структуру путей;
5. закрывается, заменяет файлы и запускается заново.

Папка `.venv`, сохранённые макросы и другие пользовательские файлы не удаляются.

## Собственные сценарии

Сценарии выполняют только известные MacroPilot команды. Это не произвольный Python-код: приложение не использует `eval` или `exec`, поэтому случайная строка не может запустить системную команду.

На вкладке **Сценарий** доступны два представления одного языка:

- **Код** — привычный текстовый редактор;
- **Граф** — свободный холст с узлами, входами, выходами и кривыми связями.

Кнопка **Код → граф** проверяет текст и создаёт связанные узлы. Кнопка **В код** в редакторе графа создаёт эквивалентный канонический сценарий. Комментарии и ручное форматирование не являются узлами, поэтому при преобразовании в граф сохраняется поведение команд, а оформление кода приводится к единому виду.

### Как собирать граф

1. Перетащите действие из палитры слева на холст или дважды щёлкните по нему.
2. Потяните связь от выходного кружка одного узла к совместимому входу другого. Белые порты задают порядок выполнения, цветные передают текст или число.
3. Начинайте поток от единственного узла **Старт**. У **Повтора** отдельно подключаются **Цикл** и **После**, у условия — **Да**, **Нет** и **После**.
4. Выберите узел и измените его параметры в инспекторе справа. Подключённое значение блокирует соответствующее ручное поле.
5. Если граф неполный или типы несовместимы, причина появится под холстом. Валидный граф можно запустить прямо из вкладки **Граф**.

Колесо мыши меняет масштаб, средняя кнопка или `Alt+ЛКМ` двигает холст, `Delete` удаляет выделение, `Ctrl+C`/`Ctrl+V` копируют узлы, а `Home` показывает весь граф. Формат `*.mpgraph` хранит узлы, связи, координаты и положение камеры; обычные `*.macro.txt` и `*.macro.json` продолжают использовать прежние совместимые форматы.

```text
# Переместить мышь за 0.4 секунды и сделать двойной клик
MOVE 500 350 0.4
CLICK left 2 0.12

# Ввести текст и нажать Enter
TYPE "Привет!" 0.04
PRESS enter

# Ждать картинку до 30 секунд, затем кликнуть по её центру
CLICK_IMAGE "images/start.png" left 30 0.9

# Дождаться сигнала, но нажать в заданной координате
WAIT_IMAGE "images/ready.png" 0 0.88
CLICK_AT 900 600

# Считать здоровье из области и использовать полученное число
OCR_NUMBER health 100 40 180 50
IF_NUMBER health < 30
    PRESS q
ELSE
    TYPE "HP: ${health}" 0.03
END

# Повторить блок три раза
REPEAT 3
    MOVE_BY 80 0 0.2
    CLICK left
    WAIT 0.3
END
```

| Команда | Назначение |
| --- | --- |
| `WAIT секунды` | Пауза |
| `MOVE x y [секунды]` | Переместить курсор в абсолютные координаты |
| `MOVE_BY dx dy [секунды]` | Отправить относительное движение мыши, в том числе для захваченного игрой курсора |
| `CLICK [button] [count] [interval]` | Клик в текущем месте |
| `CLICK_AT x y [button] [count] [interval]` | Клик по заданным координатам |
| `WAIT_IMAGE "file" [timeout] [confidence]` | Ждать появления эталона на экране |
| `CLICK_IMAGE "file" [button] [timeout] [confidence]` | Ждать эталон и кликнуть по его центру |
| `OCR_TEXT name x y width height [language]` | Считать текст из области и сохранить в переменную |
| `OCR_NUMBER name x y width height [language]` | Считать первое число из области и сохранить в переменную |
| `IF_TEXT name ==\|!=\|CONTAINS\|NOT_CONTAINS "text"` … `ELSE` … `END` | Выполнить ветку по текстовому условию без учёта регистра |
| `IF_NUMBER name ==\|!=\|<\|<=\|>\|>= number` … `ELSE` … `END` | Выполнить ветку по числовому условию |
| `DOWN button`, `UP button` | Зажать или отпустить кнопку мыши |
| `SCROLL dy` или `SCROLL dx dy` | Вертикальная или двухосевая прокрутка |
| `PRESS key` | Нажать и отпустить клавишу |
| `KEY_DOWN key`, `KEY_UP key` | Зажать или отпустить клавишу |
| `HOTKEY ctrl shift s` | Нажать сочетание клавиш |
| `TYPE "текст" [интервал]` | Напечатать текст |
| `REPEAT n` … `END` | Повторить блок команд |

Кнопки мыши: `left`, `right`, `middle`. Примеры клавиш: `enter`, `tab`, `space`, `esc`, `backspace`, `delete`, `home`, `end`, `page_up`, `page_down`, стрелки, `ctrl`, `alt`, `shift`, `cmd`, `f1`…`f20` или одиночный символ.

Преобразованная в сценарий Windows-запись сохраняет физические клавиши в виде `scan:11` или `scan:e0-4d`. Такие команды предназначены для Windows.

Для `WAIT_IMAGE` и `CLICK_IMAGE` сохраните небольшой точный фрагмент экрана в PNG, JPG или BMP. Относительный путь считается от сохранённого файла сценария. Тайм-аут по умолчанию — 30 секунд; `0` ожидает без ограничения до назначенной клавиши остановки. Сходство по умолчанию — `0.9`, допустимо от `0.5` до `1`. Эталон должен иметь тот же масштаб, что и объект на экране. Если игра запрещает снимок в эксклюзивном полноэкранном режиме, используйте оконный или безрамочный режим.

### OCR области, переменные и условия

На вкладке **Сценарий** нажмите **Выбрать OCR-область…**, выберите текст или число, задайте имя переменной и обведите нужный фрагмент экрана с зажатой ЛКМ. MacroPilot вставит готовую команду с физическими координатами. `Esc` или ПКМ отменяют выбор.

```text
# Считать надпись. auto использует языки профиля Windows.
OCR_TEXT status 720 90 260 55 auto
IF_TEXT status CONTAINS "готово"
    CLICK_AT 900 600
ELSE
    WAIT 0.5
END

# Указать язык явно и подставить результат в печатаемый текст.
OCR_NUMBER score 30 30 220 60 ru-RU
TYPE "Результат: ${score}" 0.03
```

`OCR_TEXT` сохраняет весь нормализованный текст, а `OCR_NUMBER` находит первое число: поддерживаются минус, десятичная точка или запятая и разделители тысяч. Имена переменных состоят из латинских букв, цифр и `_`, но не могут начинаться с цифры. Результат действует до конца текущего запуска сценария; повторная команда OCR с тем же именем обновляет его. Ветка `ELSE` необязательна, блоки `IF` и `REPEAT` можно вкладывать друг в друга.

Распознавание выполняется на компьютере системным движком Windows — изображение не отправляется в интернет и Tesseract устанавливать не нужно. По умолчанию используется `auto`; при необходимости последним аргументом укажите тег установленного языкового пакета, например `ru-RU` или `en-US`. Выбирайте область плотно вокруг крупного контрастного текста. Если игра не отдаёт изображение в эксклюзивном полноэкранном режиме, переключите её в оконный или безрамочный режим. OCR доступен в Windows 10 и новее; точность зависит от шрифта, масштаба и установленных языков Windows.

## Сборка Windows-пакета

Запустите `build_windows.bat`. Готовая переносимая папка появится по адресу `dist\MacroPilot`, а точка запуска — `dist\MacroPilot\MacroPilot.exe`. Сборка выполняется на Windows; результат PyInstaller нельзя корректно собрать для Windows из Linux или macOS.

После изменения `APP_VERSION` и отправки кода в ветку `main` GitHub Actions проверяет, существует ли релиз этой версии. Для нового номера версия автоматически проходит тесты, получает тег вида `v2.0.0` и два архива: `MacroPilot-windows.zip` и `MacroPilot-source.zip`. Повторные коммиты с тем же номером второй релиз не создают. Сборку также можно запустить вручную на странице **Actions → Release**.

## Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

- macOS запросит разрешение **Accessibility / Универсальный доступ** для Terminal или собранного приложения.
- В Linux лучше всего поддерживается сеанс X11. Wayland часто запрещает глобальное чтение и эмуляцию ввода; это ограничение среды, а не MacroPilot.
- Некоторые игры с античитом и приложения с повышенными правами могут игнорировать программно созданный ввод. Не пытайтесь обходить такие ограничения.
- Если игра запущена от имени администратора, MacroPilot тоже нужно запустить от имени администратора, иначе Windows может заблокировать ввод между процессами с разными уровнями прав.
- В Windows физическое относительное движение при зажатой кнопке записывается через Raw Input и воспроизводится через `SendInput`; обычные клики, курсор и перетаскивания игровых объектов также используют `SendInput`.
- OCR использует локальный системный движок Windows и установленные языковые пакеты; в Linux и macOS команды `OCR_TEXT` и `OCR_NUMBER` недоступны.
- Блокировка физической мыши использует штатный низкоуровневый Windows hook, не блокирует клавиатуру и включается только по явному флажку пользователя. Программный выход процесса также снимает hook средствами Windows.

## Безопасность и ограничения

- Не записывайте пароли, платёжные данные и другую чувствительную информацию: нажатия попадают в файл макроса в читаемом виде.
- Перед первым запуском используйте безопасную тестовую область и небольшое число повторов.
- Используйте автоматизацию только на своих устройствах и в приложениях, где такие действия разрешены.
- Назначенные глобальные клавиши управления специально не добавляются в записываемые события.
- Если сценарий сам нажмёт назначенную аварийную клавишу, выполнение прекратится.
- Для ввода символов текущая раскладка клавиатуры должна их поддерживать.
