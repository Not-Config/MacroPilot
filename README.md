# MacroPilot 1.5.0

[![CI](https://github.com/Not-Config/MacroPilot/actions/workflows/ci.yml/badge.svg)](https://github.com/Not-Config/MacroPilot/actions/workflows/ci.yml)
[![Releases](https://img.shields.io/github/v/release/Not-Config/MacroPilot?display_name=tag)](https://github.com/Not-Config/MacroPilot/releases)

MacroPilot — локальный игровой кликер и редактор макросов на Python от **Config** для записи и воспроизведения действий мыши и клавиатуры. В него также встроен безопасный сценарный язык для собственных последовательностей кликов и нажатий.

## Возможности

- запись нажатий и отпусканий клавиш;
- запись кликов, прокрутки, перетаскиваний с зажатой кнопкой и, по желанию, всех движений мыши;
- воспроизведение с регулируемой скоростью и числом повторов;
- бесконечное повторение до нажатия `F12`;
- физические Windows scan-коды и `SendInput` для корректных игровых клавиш независимо от раскладки;
- нативные события мыши Windows `SendInput` для игровых интерфейсов и перетаскиваний в Roblox;
- корректные физические координаты при масштабе экрана Windows 125–200%;
- современный тёмный интерфейс с отдельным разделом проекта и автора;
- проверка, загрузка и установка обновлений из публичных GitHub Releases;
- сохранение и загрузка макросов в читаемом формате JSON;
- удаление отдельных событий и преобразование записи в редактируемый сценарий;
- команды кликов, перемещений, текста, горячих клавиш, пауз и циклов;
- мгновенное начало записи и обратный отсчёт перед воспроизведением;
- глобальная аварийная остановка по `F12`;
- завершение записи по `F10` или `F12`;
- автоматическое отпускание зажатых приложением клавиш и кнопок мыши после остановки.

Записанные действия никуда не отправляются и хранятся локально после явного сохранения пользователем. При запуске MacroPilot обращается только к публичному API GitHub, чтобы проверить наличие новой версии. Само обновление скачивается и устанавливается только после подтверждения пользователя.

Версия 1.5.0 получила обновлённый тёмный интерфейс, страницу `by Config` и встроенный установщик обновлений. Новые версии публикуются в GitHub Releases как готовый `MacroPilot.exe` и два архива: Windows-пакет для автообновления и исходный код. Установщик проверяет структуру ZIP, доступную SHA-256-сумму и только затем заменяет файлы после закрытия приложения. Игровые движения, кнопки и колесо мыши по-прежнему воспроизводятся через нативный Windows `SendInput`.

## Скачать готовую версию для Windows

1. Скачайте [`MacroPilot.exe`](https://github.com/Not-Config/MacroPilot/releases/latest/download/MacroPilot.exe) из последнего официального релиза.
2. Переместите файл в удобную отдельную папку.
3. Запустите `MacroPilot.exe` — Python и установка зависимостей не требуются.

Готовый EXE собирается автоматически на чистом Windows-сервере GitHub Actions из опубликованного исходного кода. В релизе также остаются `MacroPilot-windows.zip` для встроенного обновления и `MacroPilot-source.zip` для разработчиков.

Пока EXE не подписан платным сертификатом издателя, Windows SmartScreen может показать стандартное предупреждение для нового неизвестного приложения. Загружайте файл только из официального репозитория `Not-Config/MacroPilot`; при предупреждении проверьте адрес загрузки и выберите **Подробнее → Выполнить в любом случае**.

## Запуск из исходного кода

1. Установите [Python 3.11 или новее](https://www.python.org/downloads/) и включите пункт **Add Python to PATH**.
2. Распакуйте исходный архив в обычную папку.
3. Дважды щёлкните `run_windows.bat`.

При первом запуске скрипт создаст виртуальное окружение и установит единственную внешнюю зависимость — `pynput`.

Запуск вручную:

```powershell
python -m venv .venv
.venv\Scripts\activate
python -m pip install -r requirements.txt
python main.py
```

## Как записать макрос

1. На вкладке **Запись** нажмите **Начать запись**.
2. Запись начнётся сразу после готовности перехватчиков, затем окно автоматически свернётся — выполните нужные действия. Автосворачивание можно выключить флажком.
3. Нажмите `F10` для завершения записи. `F12` также останавливает запись.
4. Проверьте список событий, при необходимости удалите лишние строки.
5. Заранее откройте целевое окно и нажмите **Воспроизвести**. После отсчёта MacroPilot свернётся; `F12` остановит выполнение.
6. Нажмите **Сохранить**, чтобы получить файл `*.macro.json`.

Для бесконечного цикла включите **∞ До F12** рядом с числом повторов. Поле количества повторов отключится, а макрос будет выполняться до глобального нажатия `F12`.

Если запись обычных движений мыши выключена, координаты каждого клика и вся траектория движения с зажатой кнопкой всё равно сохраняются и правильно воспроизводятся.

## Онлайн-обновления

MacroPilot проверяет последний публичный релиз в репозитории [`Not-Config/MacroPilot`](https://github.com/Not-Config/MacroPilot). Проверку также можно запустить вручную кнопкой **Проверить обновления** в шапке или на вкладке **О проекте**.

Если найдена более новая версия, приложение:

1. показывает номер версии и описание релиза;
2. запрашивает подтверждение;
3. скачивает подходящий ZIP-архив;
4. проверяет контрольную сумму и безопасную структуру путей;
5. закрывается, заменяет файлы и запускается заново.

Папка `.venv`, сохранённые макросы и другие пользовательские файлы не удаляются.

## Собственные сценарии

Сценарии выполняют только известные MacroPilot команды. Это не произвольный Python-код: приложение не использует `eval` или `exec`, поэтому случайная строка не может запустить системную команду.

```text
# Переместить мышь за 0.4 секунды и сделать двойной клик
MOVE 500 350 0.4
CLICK left 2 0.12

# Ввести текст и нажать Enter
TYPE "Привет!" 0.04
PRESS enter

# Повторить блок три раза
REPEAT 3
    MOVE_BY 80 0 0.2
    CLICK left
    WAIT 0.3
END
```

| Команда | Назначение |
| --- | --- |
| `WAIT секунды` | Пауза |
| `MOVE x y [секунды]` | Переместить курсор в абсолютные координаты |
| `MOVE_BY dx dy [секунды]` | Переместить курсор относительно текущего места |
| `CLICK [button] [count] [interval]` | Клик в текущем месте |
| `CLICK_AT x y [button] [count] [interval]` | Клик по заданным координатам |
| `DOWN button`, `UP button` | Зажать или отпустить кнопку мыши |
| `SCROLL dy` или `SCROLL dx dy` | Вертикальная или двухосевая прокрутка |
| `PRESS key` | Нажать и отпустить клавишу |
| `KEY_DOWN key`, `KEY_UP key` | Зажать или отпустить клавишу |
| `HOTKEY ctrl shift s` | Нажать сочетание клавиш |
| `TYPE "текст" [интервал]` | Напечатать текст |
| `REPEAT n` … `END` | Повторить блок команд |

Кнопки мыши: `left`, `right`, `middle`. Примеры клавиш: `enter`, `tab`, `space`, `esc`, `backspace`, `delete`, `home`, `end`, `page_up`, `page_down`, стрелки, `ctrl`, `alt`, `shift`, `cmd`, `f1`…`f20` или одиночный символ.

Преобразованная в сценарий Windows-запись сохраняет физические клавиши в виде `scan:11` или `scan:e0-4d`. Такие команды предназначены для Windows.

## Сборка одного EXE-файла

Запустите `build_windows.bat`. Готовый файл появится по адресу `dist\MacroPilot.exe`. Сборка выполняется на Windows; результат PyInstaller нельзя корректно собрать для Windows из Linux или macOS.

После изменения `APP_VERSION` и отправки кода в ветку `main` GitHub Actions проверяет, существует ли релиз этой версии. Для нового номера версия автоматически проходит тесты, получает тег вида `v1.5.0`, Windows EXE и два архива: `MacroPilot-windows.zip` и `MacroPilot-source.zip`. Повторные коммиты с тем же номером второй релиз не создают. Сборку также можно запустить вручную на странице **Actions → Release**.

## Автор и поддержка

MacroPilot разрабатывает **Config** (`Not-Config` на GitHub). Актуальные способы поддержать дальнейшую разработку будут размещаться в файле [SUPPORT.md](SUPPORT.md); на него ведёт кнопка **♥ Поддержать проект** внутри приложения.

Сообщения об ошибках и предложения можно оставлять в [GitHub Issues](https://github.com/Not-Config/MacroPilot/issues).

## Linux и macOS

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
python main.py
```

- macOS запросит разрешение **Accessibility / Универсальный доступ** для Terminal или собранного приложения.
- В Linux лучше всего поддерживается сеанс X11. Wayland часто запрещает глобальное чтение и эмуляцию ввода; это ограничение среды, а не MacroPilot.
- Некоторые игры с античитом и приложения с повышенными правами могут игнорировать программно созданный ввод. Не пытайтесь обходить такие ограничения.
- Если игра запущена от имени администратора, MacroPilot тоже нужно запустить от имени администратора, иначе Windows может заблокировать ввод между процессами с разными уровнями прав.
- Клики, курсор и перетаскивания игровых объектов поддерживаются через `SendInput`; относительное Raw Input-движение мыши при захваченном/скрытом курсоре (например, поворот камеры в режиме от первого лица) текущая версия не записывает.

## Безопасность и ограничения

- Не записывайте пароли, платёжные данные и другую чувствительную информацию: нажатия попадают в файл макроса в читаемом виде.
- Перед первым запуском используйте безопасную тестовую область и небольшое число повторов.
- Используйте автоматизацию только на своих устройствах и в приложениях, где такие действия разрешены.
- `F12` зарезервирована для остановки. Если сценарий сам нажмёт `F12`, выполнение прекратится.
- Для ввода символов текущая раскладка клавиатуры должна их поддерживать.
