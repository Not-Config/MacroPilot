# Поддержать MacroPilot

MacroPilot — независимый проект **Config** (`Not-Config` на GitHub).

Если приложение оказалось полезным, проект можно поддержать:

- рассказать о MacroPilot другим пользователям;
- сообщить об ошибке или предложить улучшение через GitHub Issues;
- помочь с тестированием новых релизов;
- финансово поддержать дальнейшую разработку по официальной ссылке ниже.
