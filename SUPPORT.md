# Поддержать MacroPilot

MacroPilot — независимый проект **Config** (`Not-Config` на GitHub).

Если приложение оказалось полезным, проект можно поддержать:

- рассказать о MacroPilot другим пользователям;
- сообщить об ошибке или предложить улучшение через GitHub Issues;
- помочь с тестированием новых релизов;
- финансово поддержать дальнейшую разработку после публикации официальной ссылки автора.

## Официальная ссылка для пожертвований

Пока не опубликована. Здесь будет размещена единственная проверенная ссылка автора. MacroPilot не показывает платёжные реквизиты из сторонних источников и не собирает платёжные данные внутри приложения.
