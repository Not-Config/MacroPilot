# Безопасность

Не публикуйте информацию об уязвимости в открытом Issue, если она может затронуть пользователей. Свяжитесь с автором через профиль [Not-Config](https://github.com/Not-Config) и согласуйте приватный способ передачи деталей.

MacroPilot не предназначен для обхода античитов, систем защиты или ограничений приложений. Используйте автоматизацию только там, где она разрешена.
